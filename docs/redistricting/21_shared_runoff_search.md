# Shared-discovery partisan search

This experiment extends the second-round searches in [19](19_runoff_optimization.md). It keeps the same modeled-seat objective, geographic checks, 2024 vote allocation and blocs; it does not add the neutral territorial loss to the partisan score or modify the neutral search. All 40 previously screened departments were reconsidered, with the same 34 eligible and six excluded for inadequate split-unit coverage. Each target starts from the previous saved maps in the same department, so no target can lose projected seats relative to the previous campaign.

For each department, each previously saved target map is scored for all five target blocs and placed in a shared archive. The search runs two rounds; each round contains target-specific annealed ReCom and greedy boundary-flip trajectories, two seeds (5101 and 5102), and 80 proposals per method and seed. Every changed, independently validated proposal is scored for all blocs, **including proposals rejected by the originating trajectory**. Whenever it improves another bloc's lexicographic (modeled seat count, first-round share tie-break) score, its map becomes that bloc's best found. Each new trajectory restarts from the target's current best in the shared archive. Maps are shared within a department, not transplanted across departments.

To focus some ReCom moves, the target's existing candidate-map districts are evaluated for closeness to a second-round switch. For a modeled finalist, closeness is the absolute distance between its modeled duel share and 50%; for a non-finalist, it is the first-round share gap to the second-place bloc. With probability 70%, an adjacent pair is sampled with weights based on the nearer of its districts (an exponential decay with scale 0.08 and a 0.05 floor). Otherwise the existing uniform-pair choice remains. Greedy flips remain unguided. This is a heuristic prioritization, not a claim that a district will flip. It does not restrict which valid maps can be shared. During the run, 76,812 changed candidate and initial-map evaluations were scored; this is not a count of unique maps.

| Target | Prior partisan scenario | Shared-search scenario | Gain in central modeled seats |
|---|---:|---:|---:|
| Extrême gauche | 85 | 88 | +3 |
| Gauche | 131 | 135 | +4 |
| Centre | 226 | 234 | +8 |
| Droite républicaine | 89 | 94 | +5 |
| Droite nationale | 159 | 165 | +6 |

For the far-left target, one additional seat in Hérault (34) came from a map generated by a right-target trajectory, and one in Loire (42) came from a left-target trajectory. This is direct evidence that cross-target sharing found useful maps. The run does not isolate the independent effects of sharing, focused moves, extra search budget, or random seeds; a controlled experiment would be needed for causal comparisons.

All figures are central predictions of the existing model, not observed deputies or guaranteed gains. Searching against model predictions can amplify errors and favor fragile modeled wins. The simulation ranges do not account for search-selection or vote-allocation uncertainty. The tested departments, population tolerance, unresolved electoral-unit coverage and the limitations of the second-round model are as documented in [19](19_runoff_optimization.md). The full run, per-department assignments and origin metadata are in `21_shared_search_runs.tar.gz` and `21_<bloc>_shared.json`. The `other` reference scenario retains the current map. Browser outputs were independently rebuilt using the full model and the same compactness calculation as before.
